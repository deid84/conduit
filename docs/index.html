Conduit

Serial · TCP · UDP monitor and Modbus gateway

Desktop app and headless API — the Hercules alternative for Linux and Windows

Download View on GitHub

How it works

One tool, two deployment modes — same REST + WebSocket API either way.

🖼

GUI mode

Tauri desktop app with a Svelte 5 frontend. Axum starts on a random loopback port; the WebView connects to it. Fully self-contained installer for Windows and Linux. 

# from crates/conduit-tauri/
cargo tauri dev
# or build a native installer
cargo tauri build
🖥

API mode

Headless Axum binary that listens on 0.0.0.0:3000, serves the embedded web UI as static files, and exposes the full REST + WebSocket API for scripting and automation. 

# build frontend, then start server
cd frontend && npm run build && cd ..
cargo run --bin conduit-api
# open http://localhost:3000

Features

Everything you need to monitor, debug, and automate serial and network devices.

core

Serial & RS-485

RS-232 and RS-485 support with full configuration: baud rate, data bits, parity, stop bits, flow control, DTR/RTS control.

core

TCP client & server

Open connections as a TCP client or listen as a TCP server. Multiple simultaneous connections in separate tabs.

core

UDP

Bind to a local UDP port, send datagrams to arbitrary hosts, and receive incoming data in the live stream.

modbus

Modbus RTU / ASCII / TCP

Full Modbus support: request builder (FC01–FC06, FC15, FC16), automatic response decoder, configurable timeout and retry.

modbus

Request builder & decoder

Build Modbus requests with a guided UI. Decoded responses display in hex, uint16, int16, uint32, int32, float32, or string — with byte swap and word swap options.

api

REST + WebSocket API

Full programmatic access: open/close connections, send data, trigger Modbus requests, subscribe to live byte streams over WebSocket.

ui

Multi-tab UI

Manage multiple connections simultaneously. Each tab has its own terminal, send bar, and Modbus panel. WebSocket stays alive across tab switches.

ui

Timestamped frame log

Every TX and RX frame is captured with direction, timestamp, and raw bytes. Export support planned for CSV and JSON.

platform

Cross-platform

GUI installer for Windows and Linux. Headless API runs anywhere Rust does — ideal for embedded Linux gateways and CI automation.

Quick start

Prerequisites: Rust (stable), Node.js ≥ 18, and cargo install tauri-cli --version "^2" for GUI mode.

# Clone the repo
git clone https://github.com/deid84/conduit
cd conduit

# Install frontend dependencies
cd frontend && npm install && cd ..

# Start the desktop app (Tauri opens a window automatically)
cd crates/conduit-tauri
cargo tauri dev
# Clone the repo
git clone https://github.com/deid84/conduit
cd conduit

# Build the frontend (embedded in the binary)
cd frontend && npm install && npm run build && cd ..

# Start the API gateway
cargo run --bin conduit-api
# Listening on 0.0.0.0:3000 — open http://localhost:3000
